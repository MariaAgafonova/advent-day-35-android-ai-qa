# Удаление задачи

Предусловия: собственная `AIQA-<run-id>-delete`, создание и исходное состояние проверены отдельно от других сценариев.

Цель: меню конкретной карточки → «Удалить». В текущем продукте **нет диалога подтверждения**; проверка отмены такого диалога неприменима. Вместо него есть Snackbar «Задача удалена» с «Отменить».

Ожидается: собственная задача отсутствует в нужной дате с учётом выполненных и прокрутки. После перезапуска без clearState она не появляется. Отсутствие в одном viewport без полного покрытия не считается доказательством.

Undo — отдельный сценарий `undo`, со своей задачей: удалить, нажать Snackbar до его исчезновения, проверить восстановление названия, даты и статуса. Истечение Snackbar до действия агента — ограничение проверки, не подтверждённый баг.

Ошибки: удалена другая карточка, задача появилась после перезапуска, Undo восстановил неверные данные. Очистка не требуется после успешного удаления; после Undo удалять только восстановленную собственную задачу.

Источники: `ui/DayScreen.kt` (TaskEvents, TaskCard), `ui/PlannerViewModels.kt`, `data/TaskRepository.kt`, `data/TaskDao.kt`, `TaskRepositoryTest.kt`.
