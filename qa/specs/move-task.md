# Перенос задачи

Предусловия: создать собственную `AIQA-<run-id>-move` на сегодня; проверить исходное имя, дату и невыполненный статус.

Цель: меню конкретной карточки → «Перенести на дату» → следующий календарный день → «Сохранить». Завтра вычисляется из даты устройства, без прибавления 24 часов. Если дата устройства сменилась в ходе проверки, остановить сценарий с причиной.

Ожидается: та же задача исчезает из исходного дня и появляется в целевом; имя и статус сохраняются. Перезапуск без clearState, переход к целевому дню и повторная проверка. Смена даты при просмотре календаря списка происходит сразу; календарь переноса требует подтверждения — это разные действия.

Ошибки/варианты: отмена календаря не переносит задачу; переход через конец месяца/года; фильтры и прокрутка не должны создавать ложное «отсутствует». При неполном обзоре отсутствие не доказано. Перенос выполненной задачи сохраняет её состояние согласно текущему DAO; отдельный вариант требует фактического запуска.

Очистка: собственная задача удаляется из целевого дня, без удаления задач других запусков.

Источники: `ui/DayScreen.kt`, `ui/Components.kt`, `data/TaskDao.kt`, `data/TaskRepository.kt`, тест `movingTaskStillRequiresConfirmationAndCanBeCancelled` в `PlannerUiTest.kt`.
