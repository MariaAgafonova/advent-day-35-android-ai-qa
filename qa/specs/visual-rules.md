# Визуальные проверки

Базовый профиль: NaTodayCalendarTest, Android API 35, Pixel 7, 1080×2400, density 420. Фактические locale, timezone, font scale сохраняются для каждого запуска. Интерфейс приложения принудительно русский независимо от locale устройства.

Ключевые состояния: пустой список, редактор с клавиатурой, заполненный редактор, календарь, обычная/выполненная карточка, Snackbar.

Проверять достижимость кнопок, границы текста и диалогов, возможность прокрутки к действиям, читаемость пустого состояния. Политика максимальной длины, числа строк и ellipsis — **unspecified**. Пересечение bounds родителя и ребёнка штатно; само по себе это не баг. Контрастность и touch target в dp не выводятся из скриншота.

Доказательства: снимок и UI-дерево одного observation_id; при подозрении — повторное наблюдение и воспроизводимые шаги. AI vision выдаёт предварительную оценку, не подтверждённый дефект. Без vision — not_checked, сохранение снимков продолжается. Проверка корректности числовых bounds относится к инструменту, не доказывает отсутствие визуальных ошибок.

Дополнительные профили: `small` (720×1280), `large-font` (1.5), `dark`. Запускать отдельно после baseline, только на эмуляторе. Исходные настройки восстанавливаются в finally; `device-restore.json` нужен для восстановления после принудительного завершения процесса.
