# Изменение статуса

Предусловия: отдельная `AIQA-<run-id>-status`, созданная на сегодня.

У приложения два состояния: `completedAt == null` (в планах) и ненулевой `completedAt` (выполнена). Статусов «в работе» и «отложена» нет.

Цель: нажать checkbox собственной задачи. Раскрыть раздел «Выполненные», проверить семантический checked=true и описание «Отменить выполнение …». Цвет и зачёркивание — дополнительные визуальные признаки, не единственное доказательство.

Сохранение: перезапуск без clearState, раскрытие выполненных, повторная проверка. Затем обратное изменение: задача возвращается в планы, checked=false, описание «Выполнить …».

Ошибки: счётчик/раздел не соответствует состоянию; статус не переживает перезапуск; обратное изменение недоступно. Отсутствующая семантика сама по себе не доказывает функциональный баг — использовать описание либо not_checked.

Очистка: удалить только собственную карточку после обратного изменения.

Источники: `data/Task.kt`, `data/TaskDao.kt`, `ui/DayScreen.kt`, `ui/PlannerViewModels.kt`, `TaskRepositoryTest.kt`.
