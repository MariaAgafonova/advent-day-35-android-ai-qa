# Создание задачи

Предусловия: debug APK «На сегодня», видимый тестовый эмулятор, выбран сегодняшний календарный день устройства. Авторизация отсутствует. Имя: `AIQA-<run-id>-create`.

Цель: создать одну собственную задачу через «Добавить задачу», поле «Что нужно сделать?» и «Сохранить».

Ожидается: название после trim, задача в выбранном дне, невыполненный статус. Проверить единственность задачи при полном обзоре списка; если список не покрыт, отсутствие дублей не доказано. Перезапустить без clearState и проверить название, дату и статус.

Ошибки: пустое/пробельное название не сохраняется; отображается «Напишите название задачи». Длинное название не должно скрывать действия; максимальная длина и правила сокращения — **unspecified**. Кириллица допустима кодом, но inputText Maestro Android не поддерживает Unicode: вариант **not_checked**, пока другой официальный механизм не подтверждён реально. Для открытой клавиатуры сохранить скриншот и проверить достижимость Save.

Очистка: удалить только задачу этого запуска после сохранения evidence; при сбое по умолчанию сохранить её для исследования.

Источники: `app/src/main/java/ru/natoday/app/ui/Components.kt` (TaskEditor), `data/TaskRepository.kt` (trim/валидация), `ui/DayScreen.kt`, `app/src/androidTest/java/ru/natoday/app/PlannerUiTest.kt`. Это источники текущей реализации; неизвестные продуктовые правила из них не выводятся.
