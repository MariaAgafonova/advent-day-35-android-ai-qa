## Локальные проверки

- `python -m pytest tools/android-ai-qa/tests -q`: 47 тестов пройдены, включая сериализацию ошибок/скриншотов отчётов и блокировку параллельных запусков. Тесты используют mock API/MCP и не заменяют проверки выше.
- Веб-клиент: локальная страница и assets вернули HTTP 200; API перечислил 9 сценариев. Через `POST /api/runs` прошли реальные сценарии создания (`20261017T185715-327b25`, 5 проверок) и смены статуса (`20261017T190220-aa741f`, 7 проверок, flow `verified`). Для каждого отчёта API отдаёт скриншоты как `image/png`; в ходе статусного сценария прогресс обновился от `0/4` до `4/4`. Одновременный запуск второго сценария запрещён.
- `:app:testDebugUnitTest --rerun-tasks`: успешно, 25 задач выполнены.
- Debug APK, Android lint и сборка instrumentation APK прошли ранее.
- `doctor --check-api` проверил текстовый запрос, tool calling, изображение и изображение вместе с tool calling на `deepseek-v4-flash`; все четыре проверки прошли. Отчёт: `20261017T183234-b92aaf`. Эти запросы расходуют API-квоту.

## Ограничения

- Дополнительные варианты пустого/длинного названия, Undo, ввода с открытой клавиатурой и профилей устройства не запускались на реальном устройстве.
- Кириллица через Maestro Android `inputText` не подтверждена; в проверенных версиях этот ввод ограничен ASCII.
- Визуальные оценки AI предварительные. Bounds UI-дерева не подтверждают контрастность, размеры в dp или отсутствие перекрытий.
- Android instrumentation tests не запускались: существующие тесты очищают данные приложения. Реальные пользовательские данные не очищались.
- Черновики в `qa/flows/draft-*.yaml` непроверены и не должны считаться прошедшими.
